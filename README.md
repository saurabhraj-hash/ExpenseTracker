# 💰 Expense Tracker

A simple and user-friendly Expense Tracker web application built using HTML, CSS, and JavaScript. It helps users manage their daily expenses, monitor spending, and maintain better financial records.

## ✨ Features

- Add new expenses.
- View all recorded expenses.
- Calculate total expenses.
- Delete expenses.
- Simple and responsive user interface.
- Easy expense management.

## 🛠️ Technologies Used

- **HTML5** – For structuring the web application.
- **CSS3** – For styling and designing the interface.
- **JavaScript** – For functionality and expense calculations.
